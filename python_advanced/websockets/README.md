# Real-time communication with WebSockets

A project focused on building real-time, bidirectional communication systems using Python and the `websockets` library.

## Features
- **WebSocket Server (`echo_server.py`)**: A persistent-connection server built with asynchronous programming (`asyncio`) that echoes back text messages to clients instantly.

## Requirements
- Python 3.x
- `websockets` library

## Usage
Run the WebSocket server locally:
```bash
python3 echo_server.py
