# Python – Inheritance & Polymorphism

This repository contains tasks and exercises for the **Python – Inheritance & Polymorphism** project at Holberton School. It explores object-oriented programming concepts such as class inheritance, method overriding, polymorphism, and relationship verification using Python.

## Learning Objectives
- Understand how inheritance allows classes to reuse behavior.
- Identify and work with parent and child classes.
- Create subclasses that extend parent behavior.
- Override inherited methods.
- Apply polymorphism to allow different objects to respond to the same method call.
- Use built-in functions like `isinstance()` and `issubclass()`.

## Requirements
- **OS:** Ubuntu 20.04 LTS
- **Python Version:** 3.8+
- **Style Guidelines:** PEP 8 compliance, executable files, and complete documentation strings for all modules, classes, and methods.
