# Python - Control Flow (Task 0)

This project is part of the Holberton School curriculum. It focuses on using control flow statements (`if`, `elif`, `else`) in Python to make decisions based on random numbers.

## Description
A script (`positive_or_negative.py`) that assigns a random integer between -10 and 10 to a variable named `number`, and then prints whether the number is positive, zero, or negative.

## Requirements
- Allowed editor: `vi`, `vim`, `emacs`, `VS Code`.
- All files will be interpreted/compiled on **Ubuntu 20.04 LTS** using Python 3.8.
- All files must be executable and end with a new line.
- Code must be PEP 8 compliant.
