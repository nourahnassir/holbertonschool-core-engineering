# Python - Exception Handling

This project explores how Python handles runtime errors and how to manage them using `try` and `except` blocks, catching specific exceptions, and writing robust, defensive code.

## Resources
* [Python Tutorial — Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html)
* [Built-in Exceptions](https://docs.python.org/3/library/exceptions.html)

---

## Learning Objectives
By completing this project, I learned how to:
* Identify common runtime exceptions (`TypeError`, `IndexError`, `ZeroDivisionError`, `KeyError`, etc.).
* Use `try` and `except` blocks correctly.
* Catch specific exception types rather than broad exceptions.
* Write functions that fail safely and predictably without crashing.
